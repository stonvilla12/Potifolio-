## Final year project: Patient registration for a health center in Mahama refugee camp

### The problem
The health center is in Mahama refugee camp, Kirehe District, Rwanda.
Patients were registered on paper. Filling in forms was slow, it used
a lot of paper, and each form had to be carried to the doctor before a
consultation could start.

I decided the real problem was not only the paper. It was that patient
information did not reach the doctor quickly. So I built the smallest
system that fixed that.

### How patient data moves

**Before:** Patient fills a paper form → form is carried to the doctor
→ consultation starts

**After:** Staff register the patient once → record is saved in the
database → doctor sees the record directly

### Project facts
- **Built with:** PHP and a database
- **Type:** Final year school project
- **Tested:** At my final project presentation
- **Users:** Registration staff and doctors

### What I left out on purpose
- Billing and payments
- Lab results and pharmacy stock
- Appointment booking

I wanted staff to learn the system quickly, so version one only does
registration and sending the record to the doctor.

### What I would do differently
- Spend more time with the staff before building, and test with them,
  not only at a presentation
- Detect duplicate patient records, because names can be spelled in
  different ways
- Work offline, because internet in a camp can be unreliable
- Add stronger security, because health data is sensitive

### What I learned
Understanding how people actually work mattered more than the code. I
want to keep working this way: understand the real problem first, then
build what solves it.
